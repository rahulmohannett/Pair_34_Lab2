# DATA 266 Lab 2 — Part 1 Colab Package

This folder is arranged for extraction directly into `My Drive/LAB2`.

After extracting, open `notebooks/p1_rag.ipynb` in Google Colab, select a GPU runtime, and run all cells.
The notebook is configured to use:

```text
/content/drive/MyDrive/LAB2
```

Input files are in `data/part1/`; generated results are written to `outputs/p1/`.

The notebook uses the public `Questions.csv` for the development run and writes `submission.csv` after processing it.
The final tagged version must still be tested on Kaggle according to the lab instructions.
